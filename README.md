# How to run
To run this code you have to first clone the https://github.com/deepseek-ai/Janus.git. 
Note Follow the instruction on how to install Janus, Flash Attention2.
Check your CUDA and pytorch version. This repostory uses the CU12.2 with torch 2.4.1.
Install streamlit in your repository.
Chnage te bacjground picture and use proper GPU to run the code. 
The proper system speciifcation: 
  1. RTX3090(ti)
  2. 12th Gen Intel® Core™ i7-12700 × 20
  3. 64 GB of RAM
